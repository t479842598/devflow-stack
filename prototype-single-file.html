4前端样式
管理 UI 组件库、设计规范、页面样式等前端资源。AI 会依据「最终选型」的前端框架推荐匹配组件库。

AI 规划助手 · UI 组件库 / 设计规范推荐

5后端框架
管理后端架构、接口定义与框架配置。AI 会生成推荐架构分层与接口设计规范，并可按统一 RESTful 模板一键生成接口清单。

AI 规划助手 · 架构与接口规范

6环境与联调
后端开发完成后的中间环节：开发环境搭建 → 测试环境部署 → 前后端联调 → 代码评审 → 预发环境验证 → 生产发布准备。「今天要处理」会汇总本步骤的逾期事项。

AI 规划助手 · 环境清单 & 联调计划

7交付管理
跟踪测试、部署、上线交付全状态。AI 上线检查清单：测试覆盖 → 缺陷清零 → 预发验证 → 发布窗口 → 回滚预案 → 运维交接。
